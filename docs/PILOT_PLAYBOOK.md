# 14-Day Pilot Playbook

How to run a 0Gauge Recovery pilot with a Dallas car-audio shop and convert it
into a paid account. The pitch is simple: *"Give me the quotes you already wrote
that went quiet. Fourteen days later I'll hand you a printed sheet showing what
came back."*

## Day 0 — Setup (30 minutes, in person)

1. Create the shop in the app (name, phone, address, reply-to email, logo,
   brand color, deposit link, disclaimer).
2. Add the owner and one employee.
3. Send a test quote email to the owner's own phone so they see exactly what
   customers get.

## Eligible customers

Only enter customers who:

- Asked the shop for a quote (walk-in, phone, or referral) — this is confirmed
  by a required checkbox on every quote
- Left a working email address
- Were quoted in the last ~60 days (fresher is better)
- Have not already bought or clearly refused

Skip: cold lists, purchased leads, anyone who never asked for a quote. That
protects the shop's sender reputation and keeps the pilot honest.

## Quote preparation

- Rebuild each eligible quote as Good / Better / Insane where possible; a
  single option is fine for simple jobs
- Mark the option the shop would actually recommend
- Set the expiration (default 30 days) — it gives the follow-ups a reason
- Use real installed prices; the report is only as honest as the quotes

## Email sequence (all manual — staff presses Send each time)

| Day | Template | Purpose |
| --- | --- | --- |
| 0 | Initial quote | Deliver the quote link |
| 2 | Two-day check-in | "Any questions?" nudge |
| 5 | Financing / lower-cost option | Remove the price objection |
| 10 | Final check-in | Polite last touch, then stop |

Special case: if a customer answers "contact me after payday", use the
after-payday reminder instead of the next step.

The follow-up queue orders this automatically and suggests the right template.
Nothing sends on its own. Customers can stop emails with one click, and the app
blocks further sends to them.

## Metrics tracked (all on the report)

Eligible quotes · total quoted value · emails sent · quote views · responses ·
cheaper-package requests · financing requests · appointments · deposits · won
jobs · **recovered revenue**.

## What counts as a qualified result

A **recovered sale** is a quote that (a) had gone quiet before the pilot,
(b) received at least one pilot email, and (c) was marked Won during the pilot
window with a real sale amount. Appointments booked and deposits paid during the
window count as leading indicators, not revenue.

## Day 7 — first report

Print the 7-day report and review it with the owner in person. Typical talking
points: views prove the emails land; responses prove customers engage; any
appointment already pays attention. Adjust: add more eligible quotes, tighten
prices, or fix the reply-to address if replies aren't arriving.

## Day 14 — close

Print the 14-day report. Put recovered revenue next to the monthly price.
The close: *"The software found $X you had already earned and nearly lost.
It costs $Y a month. Want to keep it running?"*

If recovered revenue is zero, say so plainly, review whether the quote list was
really eligible, and either extend two weeks or part as friends. Never dress up
the numbers — the printed report is the product.

## Converting to paid

1. Owner keeps the same account — nothing to migrate
2. Enter any new quotes as normal business, not just recovery
3. Set up their own Resend domain if the pilot used a shared sender
4. Schedule a 30-day check-in to review the first full month's report
